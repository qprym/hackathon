# Полный текст и нейросетевой отбор — 25 октября 2026

Реальная лента переведена на отбор DeepSeek-V4.1-Flash (`deepseek-flash`). Проверены 50 событий для U_26491, U_989 и U_6923, по три роли: 450 оценок. Статьи передаются полностью в пределах сохранённого доступного текста. Локальный демостенд обновлён сохранёнными результатами, без ключа провайдера.

## Что изменено

1. **Контекст статьи.** Убраны ограничения длины текста и количества новостных фрагментов при планировании, поиске банковских оснований, синтезе и проверке. Разбиение по 1500 символов осталось только для адресных ссылок. Журнал содержит исходную и переданную длину каждого документа. При превышении контекстного окна возвращается явная ошибка; скрытого обрезания нет. Это полный доступный текст: закрытые части публикаций и отсутствующие в источнике данные не восстанавливаются.
2. **Отбор.** Модель получает полные статьи, профиль, продукты, группу и платежный контекст; оценивает сразу CEO, CFO и казначея. В профиль входят все нормализованные признаки, агрегаты связей и десять крупнейших контрагентов с учётом прав, а не все строки платёжного набора. Оценка по ключевым словам не определяет порядок реальной ленты. Учебные сценарии сохраняют обозначенные правила.
3. **Проверка отбора.** Отдельный проход DeepSeek проверяет механизм связи, неизвестные условия, роль и основания; может исправить оценку. Локальная проверка требует допустимых ID, признаков и точных цитат. Дословная цитата заголовка допустима и отдельно помечается. Удаляются только избыточные пустые массивы внутри оценок ролей; содержательные поля и проверки не обходятся. Непроверенные черновики в персональную ленту не попадают.
4. **Кеш и очередь.** Ключ зависит от текста, профиля, модели и версии инструкции. Чтение ленты и смена роли бесплатны. Рабочий API ставит только столько новых пакетов, сколько допускает остаток квоты. Повторный клик не создаёт дубли; потерянная задача завершается ошибкой без автоматического платного повтора. Просмотр сохранённого разбора не инвалидируется из-за поступления посторонней новости.
5. **Банковская аналитика.** Для отбора документов выделены отдельная инструкция и компактная схема ID. Общая инструкция написания разбора раньше провоцировала модель написать полный ответ вместо списка источников и исчерпать лимит ответа. Исправленный этап проверен реальным вызовом: выбраны релевантные материалы по ставке и облигациям. В интерфейсе пересказ позиции экспертов с датой и PDF отделён от сценариев AI.
6. **Выборка.** Добавлены 101 публичная статья: 87 бизнес/экономика/финансы и 14 о здравоохранении. В снимке 360 реальных событий. Новый набор из 50 событий отобран по группам событий и отраслевым квотам, без использования будущих меток и баллов ранжирования. Источники: 12 публикаций ЦБ и 38 «Ведомостей»; представлены финансы, фармацевтика, промышленность, перевозки, торговля и прочие события.

Контрольные тексты уже просматривались при работе, а часть сюжетов знакома по прежним проверкам; это внутреннее сравнение, не новая слепая приёмка. После обнаружения различия снимков группы контексты обоих сравниваемых ранжировщиков приведены к фактически переданным модели. Исходные файлы сохранены; метки не менялись.

Остаются ошибки приоритета: общие макроэкономические сообщения иногда вытесняют отраслевые, особенно в профиле фармацевтики. Семантическая проверка уменьшает фактические ошибки, но не гарантирует оптимальный состав первых пяти карточек. Следующий содержательный этап — отбор итогового списка с учётом повторяющихся макротем и проверка на свежих событиях с достаточным числом полезных примеров для каждой роли. Для независимой приёмки нужна человеческая разметка.
