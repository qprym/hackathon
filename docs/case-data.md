Полный локальный отчёт с SHA-256 и номерами проблемных строк: `data/private/import-report.json`. Время записи на проверочной машине: компании 36,40 с; платежи 352,75 с; физлица 3,43 с. Это конкретный замер, не гарантия производительности другого сервера. Импорт выполняется пакетами по 250 записей, обновляет по стабильному ID, транзакция завершается для каждого файла. CLI повторно не импортирует уже учтённый SHA-256; `--force` выполняет повторное обновление. Изменение банковских материалов или доступного контекста меняет ключ кеша разбора.

Единицы `REVENUE_COMPANY` и `PAY_AMT`, период платежей и полнота выборки не указаны в задании. Числа сохраняются без конвертации; интерфейс не приписывает им рубли. Рыночная доля не рассчитывается без знаменателя рынка. Флаг `NEGATIVEMARK` трактуется по описанию задания как наличие ключевого собственника, а не негативный риск.

## Воспроизведение

Скачать файлы из ссылок на стр. 15 и 17 задания в `data/private/` с исходными именами. Скопировать `data/case/bank-manifest.example.json` в `data/private/bank-manifest.json`. Пример PowerShell из корня после запуска Docker:

```powershell
docker compose run --rm --no-deps -v "${PWD}/data/private:/case" api python -m app.case_import /case --csv
docker compose run --rm --no-deps -v "${PWD}/data/private:/case" -e OMP_THREAD_LIMIT=1 api python -m app.case_import /case --ocr
docker compose run --rm --no-deps -v "${PWD}/data/private:/case" api python -m app.case_import /case --bank --grant U_26491 U_989 U_6923 U_724 U_9371 U_11656 U_14468
```

Запускать команды последовательно. OCR занимает несколько минут и не тратит запросы LLM. Для нового файла сначала сверить дату и заголовок с PDF, затем добавить запись в локальный manifest. `date=null` + `date_kind=observed_at` означает неизвестную дату публикации и консервативное отсечение по первому импорту. Повторный импорт сохраняет эту дату.

Для небольших наборов работает «Источники и импорт», лимит файла 64 МБ. CSV-импорт через интерфейс выдаёт текущему администратору доступ к первым 100 профилям и явно сообщает об ограничении. Для полного набора предпочтительна CLI-команда, исключающая таймаут браузера. Оригиналы PDF находятся в Docker volume `source_files`; резервную копию нужно делать вместе с PostgreSQL.
