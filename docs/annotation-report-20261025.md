# Предварительная разметка — 25 октября 2026

Историческая диагностика первой выборки. Исправления, новая отраслевая выборка и проверка реальной моделью описаны в [актуальном отчёте](neural-ranking-report-20261025.md).

По запросу владельца заполнены **450 оценок релевантности** (50 событий × 3 компании × 3 роли) и **11 оценок утверждений**. Это AI-разметка по сохранённым источникам, не независимая экспертная приёмка. Новых обращений к DeepSeek не было.

## Материалы и воспроизводимость

Файлы находятся локально в `data/private/` и исключены из Git:

- `evaluation-20261024.ai-reviewed.json` — оценки 0/1/2 и комментарий к каждой из 450 ячеек;
- `evaluation-20261024.claims.ai-reviewed.json` — проверка каждого утверждения, основания и ошибки;
- `evaluation-20261024.ai-metrics.json` — результаты расчёта;
- `annotate_review_20261025.py` — явный список решений по каждому материалу, без вызова ранжирования или API моделей.

Исходные пустые наборы и ответы модели не изменены. SHA-256 исходников записан в размеченных файлах и проверен после сохранения. Прочитаны полные сохранённые тексты всех 50 событий и снимки трёх профилей; ранжирование `context-subject-v2` после чтения holdout не менялось. Оценки были записаны до запуска расчёта метрик. Содержимое публикаций сопоставлялось с профилями; независимая проверка достоверности самих публикаций во внешнем мире не выполнялась.

## Релевантность

Распределение: **439 оценок 0, 11 оценок 1, ни одной 2**. Ноль означает отсутствие достаточно применимой связи в доступных материалах, а не доказанное отсутствие любого возможного влияния. Совпадение страны, региона или слова «транспорт» не считается достаточным основанием. Например, танкер в Индии не становится фармпоставкой U_989 только из-за совпадения страны ФТС.

Средние значения — 0,0222 и 0,0444 соответственно. **Это диагностические результаты на слабом наборе, а не независимая оценка качества всей системы.** Цель 0,8 не подтверждена.

Проблемы подготовленного набора:

1. Последние 50 событий оказались материалами одного издателя, преимущественно о политике и происшествиях. Это плохая выборка для оценки финансовой и отраслевой ленты.
2. В holdout для шести сочетаний компании/роли вообще нет положительных примеров; для остальных есть только один или два. Даже идеальная сортировка здесь не достигнет 0,8. Оценщик теперь выводит `precision_at_5_ceiling` для каждого профиля.
3. В обе части попали четыре группы одинаковых либо тесно связанных сообщений: ДТП в ЕАО, ограничения Starlink, подготовка ноябрьских переговоров, транспортные ограничения в Ижевске. Группы помечены `event_group`; исходное разбиение не переставлялось задним числом.
4. Набор не проверяет новости высшего приоритета: меток 2 нет.

Проблема ранжирования тоже есть: в development сообщение о росте заболеваемости, косвенно полезное фармоптовику, не попадает в его top-5. В подборке CEO U_989 оказываются назначение главы Приморья и товарный знак Lego. Обнаруженные слабости нельзя объяснять только плохим набором.

## Утверждения

Четыре фактических утверждения подтверждаются процитированными фрагментами: два пересказа новостей и две исторические позиции банка. Результат 4/4 на столь малом архиве **не доказывает 95% для текущей версии**. Все ответы исторические, текущих утверждений `financial-v3` в наборе нет.

Из семи сценариев три имеют допустимые условные предпосылки, четыре отклонены:

- дизель / влияние: категоричное признание топлива статьёй расходов именно этого клиента без данных о парке и закупках;
- дизель / действия: общий запрет прогнозировать цены вместо запрета выводить прогноз только из этой новости;
- розничные ставки / влияние: рост любой корпоративной котировки трактуется как рост расходов, хотя для размещения средств это доход;
- розничные ставки / возможности: продуктовый признак слишком уверенно превращён в фактическое размещение денег; запрет использовать розничный индикатор сформулирован шире, чем запрет подставлять его вместо корпоративной котировки.

Часть этих ошибок уже адресована более поздней самопроверкой. Исторические тексты не переписаны и не выданы за новые ответы модели. Сценарии не включены в показатель подтверждённости фактов.

## Что следует сделать перед приёмкой

Подготовить другой набор с банковскими, отраслевыми и нерелевантными событиями, сгруппировать сообщения до разбиения, обеспечить положительные примеры для всех девяти профилей. Для настоящего временного holdout сохранить новый набор после фиксации следующей версии ранжирования. На development улучшать отбор по предмету, географии и реальным операциям; не подгонять текущий holdout.

Для проверки текущей LLM нужны новые результаты с согласованным бюджетом. Эта работа не расходовала оставшееся обращение. Полная приёмка и публичное развёртывание пока не завершены.
