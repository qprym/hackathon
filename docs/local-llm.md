# Локальная модель и временный платный API

Денежный бюджет и квота числа запросов относятся к тестам удалённого провайдера. Они не являются ограничениями продукта при локальном запуске модели.

В режиме `LLM_PROVIDER_MODE=local`:

- не требуются тарифы и денежный потолок; счётчики прежнего платного теста не ограничивают работу;
- запросы не увеличивают удалённую квоту, стоимость локальных обращений записывается как нулевая;
- по умолчанию клиент не отправляет `max_tokens`: параметры генерации определяет локальный сервер;
- полные доступные тексты и проверка оснований сохраняются;
- ключ DeepSeek не пересылается локальному серверу; при необходимости используется отдельный `LLM_LOCAL_API_KEY`;
- сохранённая история удалённых расходов остаётся доступна и помечается в интерфейсе как история.

`remote` остаётся режимом по умолчанию. Для него продолжают действовать явно заданные `LLM_REQUEST_LIMIT`, `LLM_TEST_LIMIT_RUB` и дневной бюджет. Лимит конкретной тестовой серии больше не зашит в исходный код. Режим `local` отклоняет публичный адрес DeepSeek, чтобы случайная смена флага не отключала контроль расходов удалённого API.

## Подключение

Проще всего использовать **«Настройки LLM»** в кабинете администратора. Выбрать «Локальная модель», ввести адрес сервера, ID и при необходимости токен. Сохранить с включённым «Разрешить вызовы LLM». Для фонового обновления включить отдельный флажок автоматической обработки и указать компании. Контейнеры уже имеют адрес `host.docker.internal`; локальный сервер должен быть доступен из их сети. Саму модель форма не устанавливает. Введённый ключ сохраняется только в серверном томе, API и worker читают его без рестарта. Нижеследующая настройка через окружение остаётся альтернативой; при наличии сохранённой формы она имеет приоритет над окружением.

Нужен уже работающий локальный сервер с OpenAI-совместимым `POST /v1/chat/completions`. Развёртывание весов модели и выбор GPU этим изменением не выполнялись. Адаптер проверен транспортными тестами; качество конкретных локальных весов необходимо измерить отдельно.

В локальном `.env` указать:

```dotenv
LOCAL_LLM_BASE_URL=http://host.docker.internal:8001/v1
LOCAL_LLM_MODEL_NAME=Qwen3.6 35B A3B
# Подставить точный ID модели из своего сервера:
LOCAL_LLM_MODEL_ID=your-served-model-id
LOCAL_LLM_TIMEOUT_SECONDS=600
```

Затем:

```powershell
docker compose -f compose.yaml -f compose.local-llm.yaml up --build -d --wait
```

Дополнение Compose подключает приложение к локальному серверу, очищает удалённый ключ в контейнерах и включает автоматическую цепочку импорт → оценка → полный отбор для активных профилей. Оно не запускает и не скачивает веса модели. Для другой разрешённой модели поменять название и точный ID. Если локальный сервер защищён токеном, задать `LOCAL_LLM_API_KEY`; в чат ключ не передавать.

При необходимости оператор может явно настроить `LLM_LOCAL_MAX_TOKENS` в окружении API/worker; по умолчанию параметр отсутствует. Ограничение контекста самой модели не обходится обрезкой статей: незавершённый ответ остаётся ошибкой и не становится проверенным результатом.

## Автоматическая обработка и восстановление

`AUTO_PERSONALIZATION=true`, `NEURAL_RANKING_WORKER=true`, `ACTIVE_COMPANY_IDS=U_26491,U_989,U_6923` включены local overlay. Планировщик проверяет зависимости раз в `PIPELINE_INTERVAL_SECONDS` (по умолчанию 60). Повторный импорт не создаёт дубликатов задач. Поиск доступен сразу; персональная подборка обновляется после проверки.

Указать `LOCAL_LLM_MODEL_REVISION` при смене весов/настроек с тем же API ID. `LOCAL_LLM_CONTEXT_CHARACTERS` (по умолчанию 120000) ограничивает технический размер входного пакета, а не расход денег. Этот предел нужно согласовать с реальным окном сервера; число символов не равно числу токенов. Одна слишком большая статья вызывает ошибку совместимости, не усечение текста.

Worker продлевает lease каждые треть `JOB_LEASE_SECONDS`; новый владелец исключает запись результата прежним. Анализ пользователя и отбор выполняются в разных линиях. Добавление статей не отменяет готовый снимок, но требует следующего поколения; изменение источника или профиля инвалидирует его. Сохранённые шаги используются повторно только при точном совпадении входа и инструкций.

Это технические механизмы приложения. Производительность GPU, допустимая конкурентность сервера и качество выбранных весов пока не проверены; модель в этом этапе не установлена.
