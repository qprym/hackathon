# Отчёт по заданию «Новостная аналитика»

Состояние на **25 октября 2026 года**. Основание — исходный PDF в корне, 18 страниц. Ниже сопоставлены задачи, критерии, ограничения, результат и комплект сдачи.

Локальная реализация и импорт кейса работают. Независимую разметку выполнит владелец проекта; сервера пока нет, развёртывание подготовлено локально. Precision@5 ≥0,8 и подтверждённость ≥95% пока не заявляются.

Последний DeepSeek-повтор использовал **1 запрос**, всего **63/64 и 28,34499 ₽ из 30 ₽**. На полную проверку не хватило денежного резерва; результат не опубликован. Офлайн найдена и исправлена причина утверждения о якобы уже заполненном календаре. Текущая проверка — financial-v3; успешная live-приёмка этой версии ещё предстоит. [Журнал](deepseek.md).

## Как проверить текущую версию

1. Открыть http://localhost:8080 и войти demo / demo-alfa-2026.
2. Выбрать U_26491, U_989, U_6923 и сравнить ленту для CEO, CFO, казначея. «Косвенная связь» не означает установленную финансовую экспозицию; ФТС не доказывает торговлю конкретным товаром.
3. В «Контексте компании» проверить поля, расчёты, группу и недостающие сведения. В «Аналитике банка» открыть страницы девяти материалов и оригинальные PDF.
4. [Последний запуск](http://localhost:8080/?run=0434a1c9-dea5-43b8-82fa-91f2e650593e) показывает остановку по бюджету. [Предыдущий успешный](http://localhost:8080/?run=1eb54ae8-ee3f-4b5b-9ee6-f7d5afe3a387) доступен без оплаты и помечен устаревшей проверкой.
5. «Качество и бюджет» отдельно показывает LLM, учебные сценарии, выборку для задержек, ошибки источников за сутки и общую квоту.
6. [Форма разметки](http://localhost:8080/review.html): выбрать data/private/evaluation-20261024.json. Сначала 30 development, затем 20 holdout; оценки не заполнялись автоматически. [Инструкция](evaluation.md).
7. Для полного сценария без оплаты запустить scripts/verify-local.ps1: отдельная БД, браузерные проверки, миграции и восстановление очереди на 8081.
8. [Сценарий демонстрации](demo.md) и [развёртывание](deployment.md).

## Ограничения 01–06, стр. 11–12

| № | Требование | Выполнение и границы |
| --- | --- | --- |
| 01 | Не сводить продукт к пересказу | Структура последствия/условия/риски/действия и контекст реализованы. Деморежим прямо обозначен; общее качество реальной модели ещё не аттестовано. |
| 02 | Банковская аналитика — существенная часть | Реальные материалы импортированы, поиск обязателен, банк отделён от AI, проверяется применение позиции. В деморежиме отображаются фрагменты, а не выдуманный содержательный синтез. |
| 03 | Персонализация глубже отрасли | Продукты, ФТС, география, связи, концентрация, роль, возраст, численность и другие поля передаются в контекст. Суммы кредита/валюты торговли не выдумываются. |
| 04 | Только разрешённые LLM, ≤500 ₽/день | Allowlist из шести моделей. Используется `deepseek-flash` из разрешённого семейства. Общий предел локального теста — 30 ₽, глобальная квота — 64 обращения; использовано 63. Действует также дневной предел не выше 500 ₽. Неудачные вызовы расходуют квоту; перезапуск/полночь её не сбрасывают. Проверено конкурентными тестами и реальными обращениями. |
| 05 | Неполные, неоднозначные и шумные данные | Пропуски остаются неизвестными; повторные строки отражаются в отчёте; единицы не присваиваются; неизвестные контрагенты и OCR/старые материалы обозначаются; ошибки источника допускают явно помеченную аннотацию либо отказ. |
| 06 | Безопасность AI и данных | Серверные права, снимок доступа запуска, повторная проверка worker, защита CSRF, HttpOnly-сессии, ограничение входа, доменный allowlist/SSRF, недоверенные тексты, журналы и ограниченный набор инструментов. Это архитектура прототипа, не банковская аттестация безопасности. |

Стр. 13 допускает несколько вариантов архитектуры. Выбран один агент, собственные правила/поиск, структурированный JSON и PostgreSQL без отдельной embedding-модели. Мультиагентность и рекламные предложения банковских продуктов не обязательны для кейса и не добавлялись ради формального соответствия.

## Приложения, стр. 15–18

**Данные клиента:** поддержаны все перечисленные поля: SYNTHETIC_U, ORG_TYPE, OKFS_NAME, COMPANY_AGE_YEARS_GRADATION, ECO_MARK_LABEL, MAINOKVED_CODE/NAME, NEGATIVEMARK, AMOUNT_WORKERS_FNS_GRADATION, AMOUNT_WORKERS_SPARK_GRADATION, CL_TYPE, семь признаков продуктов (включая FACTORING_MARK), FTS_FLAG/COUNTRY_NAME, REVENUE_COMPANY, GROUP_ID, CITY, REGION. Связи физлиц и платежей определяются по колонкам, а не неоднозначному имени файла из PDF. Данные города/РЦ физлица не используются для вывода его роли или раскрытия личности.

**Аналитика:** загружены все 9 файлов из папки. Перечень и расхождение с названием Commodities performance описаны в [case-data.md](case-data.md). Банк не получает авторство сценария модели, исторические даты сохраняются.

**Модели:** разрешены Gemma 4 26B A4B, GLM-5.3-Flash, Qwen3.6 35B A3B, DeepSeek-V4.1-Flash, Qwen3-VL-30B-A3B-Instruct, Kimi-K2.6. По выбору пользователя все этапы локального теста используют самую дешёвую модель прямого DeepSeek API — `deepseek-flash`, соответствие семейству проверено по официальной документации. OCR остаётся локальным. Платные фоновые анализы новостей не включены.

## Что осталось для полной приёмки

1. Получить успешный live-разбор по текущим правилам и проверить уточняющие вопросы. Оставшееся обращение и 1,65501 ₽ не расходуются автоматически; увеличение требует отдельного решения пользователя.
2. Выполнить независимую разметку. Подготовлены 50 новых событий, 450 пустых оценок и 11 утверждений двух доступных опубликованных live-разборов. Эти разборы исторические; для аттестации текущей версии нужны её результаты.
3. Подтвердить у организаторов единицы выручки/платежей, период и неоднозначные строки. Ограничения остаются видимыми; доли выборки не превращаются в долю рынка.
4. После появления сервера выполнить HTTPS-развёртывание. Локальный комплект подготовлен; внешнее демо не опубликовано.
5. Репозиторий приватный; GitHub API подтвердил отсутствие доступа у alfa-hack-2026. Выдача доступа требует отдельного подтверждения владельца. Независимая оценка и онлайн-демо не подменены локальными тестами.
