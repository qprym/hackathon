# Учебные CSV

Полностью синтетические компании, лица и платежи. Ни один ID не обозначает реальную организацию или человека. Суммы заданы в рублях, платежи — вымышленный агрегат за один месяц.

Начальные интерактивные профили создаются `app.seed` с префиксом `demo-`. CSV с префиксом `sample-` предназначены для проверки импортера и **не являются данными организаторов**. При загрузке этих CSV оставьте включенной отметку синтетического материала. Тогда учебные компании используют демонстрационный новостной корпус.
